# 🌲 ForestMSG

**Децентрализованный, анонимный и устойчивый к цензуре мессенджер.**

ForestMSG — это P2P-мессенджер, построенный на принципах приватности, децентрализации и свободы общения. Он не имеет серверов, не требует номера телефона и не оставляет следов. Ваши сообщения — только ваши.

# ПРОЕКТ В АКТИВНОЙ РАЗРАБОТКЕ!!!

---

## 🚀 Основные возможности

- **Полная децентрализация** — нет серверов, нет единой точки отказа.
- **Анонимный транспорт** — трафик идёт через **I2P** (внутренний) и **Tor** (выход в Clearnet).
- **Сквозное шифрование** — AES-256-GCM + Ed25519 подписи.
- **P2P-доставка** — через BitTorrent (DHT + трекеры).
- **Криптографическая идентичность** — без номеров телефонов и email.
- **Многоуровневая структура сообщений** — текст, аудио, видео, изображения, документы.
- **Асинхронная доставка** — через I2P-почту (в разработке).
- **Открытый код** — GPLv3.

## 📦 Технологии

| Компонент | Технология |
|-----------|------------|
| **Язык** | C# (.NET 10) |
| **UI** | Eto.Forms (кроссплатформенный) |
| **Криптография** | Chaos.NaCl (Ed25519, X25519), AES-GCM |
| **P2P** | MonoTorrent (BitTorrent, DHT) |
| **Анонимность** | DotI2p (I2P), Tor |
| **QR-коды** | QRCoder, ZXing.Net |
| **Архивация** | System.IO.Compression (ZIP) |
| **Логирование** | Serilog |
